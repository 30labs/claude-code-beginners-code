● I've created CLAUDE.md for this repo. It covers:

  - Commands: how to run all the tests, one test, or tests
    matching a name with uv run pytest, and how to run the CLI
    on the sample bank.csv. I ran these: all 19 tests pass and
    the CLI works on the sample data. There's no linter,
    formatter or build step, and the file says so.
  - Architecture: ledger.py holds the calculation logic with no
    side effects, and tally.py is the command-line interface.
    Tests call main(argv) directly and check the printed output.
    Bad arguments are rejected by custom argument-type
    functions and exit with code 2.
  - Conventions:
    - Money is always stored as Decimal, never as a float.
    - totals reports money in and money out as positive numbers.
    - When expenses are tied, largest_expenses keeps them in
      file order, and a test checks this.
    - The tests match the output's fixed column widths exactly,
      so changing the formatting will break them.
