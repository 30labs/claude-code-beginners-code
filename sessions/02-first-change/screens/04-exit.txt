● I added --month. Running python tally.py bank.csv --month
  2026-08 now counts only August entries. All 9 tests pass, and
  on the real bank.csv it prints in 3218.90, out 1803.90, net
  1415.00, which matches the August rows added up by hand.

  - ledger.py: a new in_month(entries, year, month) function
    keeps only the entries from that month.
  - tally.py: the new --month option takes YYYY-MM and filters
    the entries before they're totalled. A value that isn't in
    that form, like 2026-13 or 2026-8, gets a normal usage
    error. Without --month, it counts everything as before.
  - test_ledger.py:
    - I added two September rows to the shared test CSV and
      updated the existing test_totals numbers to match.
    - New tests check that the filter keeps the right month,
      that the same month in a different year isn't counted, and
      what the command prints with --month 2026-08.
    - A parametrized test checks that five bad values are
      rejected.
