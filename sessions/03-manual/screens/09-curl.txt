● I added --top N. All 19 tests pass, and the option works on
  bank.csv:

  $ python tally.py bank.csv --top 3
  in      6418.90
  out     3312.10
  net     3106.80

  2026-08-02  Rent                    1450.00
  2026-09-02  Rent                    1450.00
  2026-08-14  Electricity               96.30

  How it behaves:
  - The totals still print first. The list comes after a blank
    line and shows expenses as positive amounts, the same way
    out does.
  - It works with --month, so --month 2026-08 --top 3 ranks only
    August's expenses.
  - Money coming in is never listed. If you ask for more than
    there are, you get all the expenses.
  - When two expenses are the same size, they stay in the order
    they appear in the file.
  - N must be a whole number of 1 or more. Values like 0, -1,
    two or 1.5 stop with a usage error (exit code 2), the same
    way a bad --month does.

  Changes:
  - ledger.py: a new largest_expenses(entries, n) function.
  - tally.py: the --top option and a count_arg check for its
    value, written like the existing month_arg.
  - test_ledger.py: 10 new tests covering the ranking order,
    that income is left out, asking for more than exist, ties,
    the printed output with and without --month, that nothing
    extra prints without --top, and the bad values.

  I haven't committed anything.
