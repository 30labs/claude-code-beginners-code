● Tally is a small Python command-line tool (3.12 or newer, no
  runtime dependencies) that sums up a bank CSV export.

  - ledger.py reads a CSV with date,description,amount columns
    into Entry records. It uses Decimal so money amounts stay
    exact. totals() returns money in (positive amounts) and
    money out (negative amounts, shown as positive numbers).
  - tally.py is the command-line entry point. It takes a CSV
    path and prints the in, out and net totals.
  - bank.csv is a sample export with 11 transactions.

  To run it on the sample:
  uv run python tally.py bank.csv
  in      6418.90
  out     3312.10
  net     3106.80

  Tests: pytest is set up as a dev dependency and managed with
  uv (there's a uv.lock). To run the tests:
  uv run pytest
  uv creates the .venv and installs pytest the first time you
  run it. I ran it just now and it passed: 1 passed. There's
  only one test, test_ledger.py::test_totals, which covers
  reading a small CSV and checking the totals. Nothing tests the
  command-line output or malformed input.
