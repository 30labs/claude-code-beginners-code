  Changes:
  - ledger.py: a new function in_category(entries, rules,

    to that category.
  - tally.py:
    - A new category_arg rejects a blank name with exit code 2,

  Decisions to check:
  - Income counts too. Any entry the rules put in the category
    is counted, not only expenses. For example, a Refund Market
    of +5.00 would add to in for groceries. --category
    uncategorised therefore shows your salary as income.
  - Unknown names are an error. Otherwise a typo like grocery
    would quietly print zeros. The error lists the valid names.
    Matching is exact, so Groceries is also rejected.
  - uncategorised is accepted as a name, for entries no rule
    matches.
